# 🚀 My Portfolio

A professional, responsive, and minimalist portfolio website built with **React** and **Vite**. This project focuses on clean code architecture, modularity, and demonstrating a solid full-stack skill set.

## 📝 Description

This portfolio project showcases my journey and capabilities as an IT student and Full-Stack Developer. It emphasizes a "Clean Code" approach, where business logic, utility hooks, and static data are cleanly separated from the UI components to ensure scalability, precision, and high readability.

### Key Updates & Technical Implementation:
- **Custom Hook Architecture:** Real-time logic (such as clock synchronization) is extracted into custom hooks (e.g., `useTime`), demonstrating clean side-effect management in React.
- **Interactive Skills Section:** Features a dynamic, mobile-friendly grid layout with hover & tap tooltips for seamless interactivity across desktop and mobile devices.
- **Enhanced UI/UX:** Streamlined, responsive layouts utilizing utility-first styling with flex and grid systems.
- **Data-Driven Design:** All technical skills, project details, and section contents are managed via centralized data models for effortless maintenance.

## 🛠️ Tech Stack & Skills

- **Backend Architecture:** Java, Spring Boot, Spring Security, RESTful APIs, Maven
- **Frontend & UI:** React.js, Vite, Tailwind CSS, Bootstrap, HTML5, CSS3
- **Databases:** MySQL (Workbench), SQLite
- **DevOps & Tools:** Docker (Basic), Git, Vercel

## 📂 Project Highlights

- **Interactive Skills Showcase:** Responsive 7-column desktop grid (adaptive for mobile) with accessible tap-to-view tooltips.
- **Real-Time Digital Clock:** Live-synchronized clock component utilizing efficient state management and interval cleanups.
- **Modular Architecture:** Highly reusable UI components (`Navbar`, `About`, `Skills`, `Headers`) built with clean component-driven patterns.
- **Optimized Deployment:** Production-ready build setup optimized for deployment on Vercel.
